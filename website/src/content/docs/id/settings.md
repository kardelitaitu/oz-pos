## Pengaturan toko

Nama usaha, mata uang, tata letak struk, dan bawaan perangkat keras
dikonfigurasi di sini dan tersinkron ke setiap register.

## Data lokal

Semua data disimpan secara lokal di setiap perangkat dan tersinkron ke
penyimpanan cloud tenant. Cadangan database lokal dapat diekspor untuk
pemulihan bencana.

## Keamanan

Nilai uang selalu disimpan sebagai satuan minor bilangan bulat; akun staf
berbasis PIN dengan izin berbasis peran, dan setiap tindakan diaudit.
