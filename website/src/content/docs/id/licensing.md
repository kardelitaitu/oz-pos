## Paket

Paket adalah `trial`, `pro`, `premium`, dan `enterprise`. Uji coba 90 hari
(`trial`) membuka seluruh produk; paket berbayar menambahkan lebih banyak
toko, register, gudang, sinkron cloud, dan fitur otomatisasi.

## Kedaluwarsa dan tenggang

Langganan memiliki tanggal kedaluwarsa dan masa tenggang. Saat langganan
berakhir, aplikasi memasuki masa tenggang dan tetap berfungsi offline hingga
tanggal tenggang, lalu turun ke paket gratis.

## Batas perangkat

Setiap paket berbayar mengizinkan sejumlah register teraktivasi. Perangkat
terikat ke perangkat keras dan dapat dicabut oleh admin tenant.
