feat(settings): batch setSettings API — atomic multi-key write in one IPC call

Replaces N parallel setSetting calls with a single setSettings(entries, userId)
in KDS (5 keys) and Inventory (2 keys) workspace cards.

Rust (desktop-client):
- New set_settings command: accepts HashMap<String, String> + user_id. Opens
  single transaction, calls Settings::set_tracked for each entry, commits,
  publishes one SettingsUpdated event with all changed keys.
- Registered in invoke_handler.

Front-end:
- setSettings(entries: Record<string, string>, userId: string) in settings.ts
- WorkspaceKdsSettings: 5 parallel setSetting → 1 setSettings call
- WorkspaceInventorySettings: 2 parallel setSetting → 1 setSettings call
- Existing setSetting preserved for single-key callers.

Future: scoped set_settings_scoped variant + empty-entries guard.
