fix(ui): prevent infinite render loops from unstable l10n refs across 9 components

Root cause: Adding `l10n` to useCallback/useEffect dependency arrays (from the
exhaustive-deps fix) created infinite re-render loops when the test mock or
provider returns a new `l10n` object on every render. Pattern:
render → new l10n → callback recreated → effect re-fires → setState → render → loop.

Fix: Standard React ref pattern — replace direct `l10n` references in callbacks
and effects with `l10nRef.current` (via `useRef(l10n)`), removing `l10n` from
dependency arrays while still using the latest value.

Files changed:

  - ui/src/features/inventory/StockCountsScreen.tsx (load useCallback)
