fix(settings): wire workspace cards to IPC + hardware IPC bridge + i18n fix

Workspace cards (store-pos, restaurant-pos, kds, inventory):
- SettingsPage now resolves terminalId via getDeviceId() on mount and passes
  it with sessionToken to all 4 workspace cards, fixing hidden printer/scanner
  sections and enabling hardware config visibility.
- Store POS: handleSave calls setReceiptSettingsScoped to persist receipt
  settings; hw.save(sessionToken) bridges to filesystem IPC.
- Restaurant POS: handleSave persists showTableNumber via setReceiptSettingsScoped
  and courseFiring via setSettingScoped; hw.save(sessionToken) bridges hardware.
- KDS: handleSave persists 5 settings (soundEnabled, yellow/red thresholds,
  autoAcknowledge, density) via setSettingScoped with 'kds.'-prefixed keys.
- Inventory: handleSave persists lowStockThreshold + deductionPreferWarehouse
  via setSettingScoped with 'inventory.'-prefixed keys.

Hardware IPC bridge (useTerminalHardware.ts):
- Added toHardwareSettingsDto() and mergeIpcSettings() helpers to extract/merge
  the 5-field printer+scanner DTO subset from/to the full TerminalHardwareProfile.
- loadProfile is now async: after loading from localStorage, calls
  getHardwareSettings() IPC and merges printer/scanner values on top.
- save() now accepts optional sessionToken param; when provided, calls
  setHardwareSettingsScoped to bridge the printer+scanner subset to
  terminal_profiles/{id}.json on disk. Falls back to localStorage-only
  when IPC is unavailable (dev mock, non-Tauri env).
- Fixed corrupted JSON recovery path to call setProfile before early return.

i18n (SyncSection.tsx):
- Wrapped hardcoded "Toggle" sr-only text in Localized to match project standard.
