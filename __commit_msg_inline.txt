fix(test): replace dangerouslyIgnoreUnhandledErrors with targeted rejection handler

Removed the blanket `dangerouslyIgnoreUnhandledErrors: true` from
vite.config.ts which silently swallowed ALL unhandled promise rejections.

Added a targeted `process.on('unhandledRejection')` handler in
test-setup.ts that:
- Filters known noise (Fluent missing keys, React act() warnings,
  DOM nesting, punycode deprecation) — same patterns as the existing
  console.error suppressor
- Logs all other rejections as console.warn so they're visible
  without failing the suite

All 3,228 tests pass with 0 failures.
