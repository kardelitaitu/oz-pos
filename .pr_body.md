## Summary

Release **v0.0.20** is a major maintenance and documentation-focused milestone. It hardens the build pipeline, stabilizes long-standing flaky tests, cleans the UI quality gates, refreshes top-level documentation, and lands the architectural decision for the R2/R5 DB-extraction and platform-split work.

## Highlights

- **🏗️ R5/R2 — DB Extraction & Platform Split (ADR #32)**
  - Added ADR #32 documenting the dual-path migration of `crates/oz-core/src/db/` into `modules/<domain>/repository.rs` and the mechanical split of `platform/core/src/settings.rs` and `platform/kernel/src/kernel.rs`.
  - Refactored `platform/core/src/settings` into focused sub-modules (`raw.rs`, `keys.rs`, `typed.rs`) with extracted `test_helpers.rs`.
  - Split `platform/kernel/src/kernel.rs` into `kernel/` sub-modules (`types.rs`, `lifecycle.rs`, `dependency.rs`).
  - Backfilled split-sanity tests for both modules.

- **🖥️ UI Quality Gates**
  - Fixed all 37 remaining ESLint warnings (`react-hooks/exhaustive-deps`, `react-refresh/only-export-components`, `consistent-type-imports`).
  - Fixed pre-existing UI failures: `TS6133` in `SessionLockScreen.test.tsx`, 9 ESLint errors, and 3 failing unit tests.
  - Reinstalled `ui/node_modules` and repaired a missing ESLint formatter issue.

- **🔧 Build, Packaging & Dependency Hardening**
  - Added `allowScripts` approval policy in `ui/package.json` for `esbuild` and `msw`.
  - Added `engines.npm: ">=11"` to `ui/package.json`.
  - Propagated `npm ci --no-audit --no-fund --ignore-scripts` to CI, packaging scripts, release scripts, coverage scripts, and launch-test docs.
  - Removed an accidental empty `package-lock.json` at the workspace root and added `/package-lock.json` to `.gitignore`.
  - Addressed 7 high-severity npm security vulnerabilities (`brace-expansion`).
  - Pinned install-script approvals for `esbuild` and `msw`.

- **🧪 Test Reliability**
  - Stabilized flaky keyring/credential tests with unique naming, retry/poll loops, and RAII cleanup guards across Windows, macOS, and Linux.
  - Extracted Windows `CredentialGuard` into `test_helpers` and reused it for macOS/Linux cleanup.
  - Fixed `cargo clippy --workspace --all-targets -- -D warnings` violations, including `clippy::clone_on_copy` for `ModuleStatus` and other warnings.

- **📚 Documentation Refresh**
  - Updated `README.md`, `docs/ARCHITECTURE.md`, `docs/QUICKSTART.md`, and `docs/dev-experience-2026-07-20.md` with current metrics (5,221+ Rust tests, 214 UI test files / 3,230+ tests, 48 `.ftl` files, 98 migrations), Node.js ≥22 / npm ≥11 prerequisites, Vite 6, and corrected locale/theme paths.
  - Resolved remaining stale findings in `docs/ARCHITECTURE.md` (scaffold crates now implemented, LICENSE note, 618 IPC endpoints).
  - Updated `docs/ROADMAP.md` with per-feature Fluent bundles, removed Thai locale references, and updated test counts.
  - Corrected `docs/WHITEPAPER.md` HAL description to the async-trait + `DriverRegistry` model.
  - Aligned `.agents/AGENTS.md` version lock with root `AGENTS.md`.
  - Backfilled `CHANGELOG.md` with the full `[0.0.20]` release notes.
